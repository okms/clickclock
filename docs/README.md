# Documentation index

| Area | Path | What it is |
|---|---|---|
| Specification | `spec/` | The feature set, written without reference to any implementation. Requirement IDs are stable and are referenced by tests and commits. Start with `spec/00-overview.md`. |
| Architecture | `design/architecture.md` | How we build it, the options considered, and a critical review of the chosen approach. |
| Decisions | `design/decisions/` | Architecture Decision Records. One file per decision, never edited after acceptance, only superseded. |
| UI | `design/ui.md` | Design system, screens, states, and copy. The visual reference is `../design/prototype.html`. |
| Plan | `plan/milestones.md` | Ordered milestones broken into subagent-sized tasks. |
| Briefing | `plan/subagent-brief-template.md` | The template every implementation brief uses. |

Working rules for agents are in `../AGENTS.md`.
