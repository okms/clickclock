# Out of scope

These are deliberate. They keep the product a timer rather than a system.

- **Projects, clients, tasks, tags.** One total per day, nothing to choose before starting.
- **Multiple users or shared data.** One person, one computer.
- **Sync, cloud, accounts, backups to a service.** The data is a local file the user owns.
- **Invoicing, rates, money.**
- **Timesheet integration** with any external system.
- **Reminders and notifications** beyond the state shown in the main view and tray.
- **Mobile or web versions.**
- **Detailed activity logging** (which applications were used, screenshots, and so on).
  The product knows only whether input happened, never what it was.
