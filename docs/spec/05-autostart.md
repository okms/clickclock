# AUTO: Start with the computer

## Requirements

### AUTO-01 Launch at login — Baseline
The user must be able to choose whether the product launches automatically when they log in
to the computer. The choice is made from within the product.

### AUTO-02 Default — Baseline
Launching at login is **on** by default the first time the product is run.

### AUTO-03 Never counts on its own — Baseline
An automatic launch follows `TT-08`: the product comes up Paused or Stopped, never Running.

### AUTO-04 The choice is remembered and reflected — Baseline
The preference is persisted and the product's view always shows the current setting. If the
computer refuses the change, the product says so and shows the setting that is actually in
effect.

### AUTO-05 Per user — Baseline
The setting applies to the current user account only and never requires elevated
privileges.
